# Интеллектуальная система динамического ценообразования для интернет-магазина

Прототип, разработанный в рамках ВКР (бакалавриат, 09.03.03 «Прикладная информатика»).

## Состав
- `src/prepare_data.py` — очистка исходных продаж и агрегация к уровню «товар-неделя»;
- `src/train_model.py` — формирование признаков и обучение модели прогноза спроса (LightGBM, функция потерь Tweedie, монотонное ограничение −1 на ценовые признаки), сравнение с базовыми прогнозами, случайным лесом, XGBoost, CatBoost и пуассоновской GLM;
- `src/optimize_price.py` — подбор оптимальной цены перебором сетки ±15% с ограничениями (маржа ≥ 10%), ретроспективная оценка экономического эффекта;
- `src/recommend_next_week.py` — рекомендации цен на следующую неделю после конца данных (боевой режим работы системы);
- `src/validate_price_response.py` — диагностическая проверка согласованности прогнозируемой и наблюдаемой реакции продаж на изменение цены (вспомогательный сценарий анализа);
- `src/diagnose_price_change.py` — диагностика артефакта признака «изменение цены» (вспомогательный сценарий анализа);
- `src/sensitivity_analysis.py` — анализ чувствительности эффекта: ширина ценовой сетки, усиление модельной ценовой реакции, бутстреп по товарам;
- `src/placebo_test.py` — плацебо-тест: обучение на ценах, перемешанных по времени внутри товара только в обучающем периоде (временная утечка исключена), и сравнение эффекта с реальной моделью;
- `src/bootstrap_test.py` — парный бутстреп-тест разности WMAPE модели и базовых прогнозов (10 000 повторных выборок по товарам);
- `src/app.py` — веб-интерфейс менеджера (Streamlit): рекомендации цен, карточка товара, журнал решений (SQLite);
- `tests/test_pipeline.py` — автоматические тесты конвейера (pytest, 8 тестов).

## Данные
История продаж интернет-магазина (розничный канал B2C): товар, дата, категория, флаг акции, количество, суммы закупки и продажи; 835 155 строк за 57 недель (29.09.2025 — 26.10.2026), 5 895 товаров из 117 категорий. Исходный файл выгрузки в формате XLSB размещается по пути `../ВКР_финал/Новый датасет.xlsb` относительно папки `Прототип` (в репозиторий не включается); путь задаётся в `src/prepare_data.py`. После очистки, агрегации и фильтрации формируется набор уровня «товар-неделя»: 192 154 наблюдения по неделям с продажами (212 478 после восстановления нулевых недель) по 4 118 товарам.

## Запуск
```bash
pip install -r requirements.txt
python src/prepare_data.py           # подготовка данных (один раз)
python src/train_model.py            # обучение модели
python src/optimize_price.py         # расчёт рекомендаций и эффекта
python src/sensitivity_analysis.py   # анализ чувствительности эффекта
python src/placebo_test.py           # плацебо-тест (перемешанные цены)
python src/bootstrap_test.py         # парный бутстреп-тест разности WMAPE
python src/recommend_next_week.py    # рекомендации на следующую неделю
python -m pytest tests -v            # автоматические тесты
streamlit run src/app.py             # веб-интерфейс
```

## Результаты (проверочный период — последние 8 недель)
- WMAPE прогноза спроса: 45,0% (наивный прогноз — 49,5%, скользящее среднее — 46,3%, случайный лес — 47,0%, XGBoost — 46,3%, CatBoost — 45,9%, пуассоновская GLM — 110,0%), MAE — 9,41 шт., смещение уровня спроса — +3,5%. Из ML-моделей лучший результат показал LightGBM, что и обосновывает его выбор; преимущество над наивным прогнозом и скользящим средним статистически значимо (парный бутстреп по товарам, 10 000 повторных выборок: разность к наивному прогнозу −4,5 п.п., 95% ДИ [−5,0; −3,9], к скользящему среднему −1,3 п.п., 95% ДИ [−1,9; −0,8]; p < 0,001 в обоих случаях — `reports/бутстреп_тест.json`);
- расчётный прирост прибыли в рамках используемой модели при рекомендованных ценах: +26,0% к фактическим ценам и +133,7% к стратегии «себестоимость + 30%» (не подтверждён реальным внедрением и требует проверки в A/B-тесте);
- устойчивость эффекта (`reports/анализ_чувствительности.json`): сетка ±5% → +9,0%, ±10% → +17,4%; усиление модельной ценовой реакции → +20,3%; бутстреп-интервал модельной оценки по составу товаров — 95% [24,9%; 27,2%]; порог оптовых выбросов 50/200 единиц (в работе — 100) → эффект +26,2%/+25,8%; наценка базовой стратегии 20%/40% (в работе — 30%) → превосходство +239,5%/+81,4%;
- диагностическая проверка ценовой чувствительности (`reports/проверка_ценовой_чувствительности.json`): совпадение знака реакции модели с фактическими изменениями продаж — 57,5%, ранговая корреляция Спирмена — +0,21; проверка носит диагностический характер и не подтверждает достоверность ценовой реакции;
- оценённая моделью эластичность спроса: медиана −0,65 (неэластичных позиций — 84,3%) — по модулю ниже средней эмпирической оценки мета-анализа Tellis;
- плацебо-тест (`reports/плацебо_тест.json`): модели, обученные на ценах, перемешанных по времени внутри товара только в обучающем периоде (исходная согласованная во времени связь цены и продаж разрушена), показывают близкий WMAPE (44,9–45,0%) и даже больший модельный «эффект» оптимизации (35,4–36,2% против +26,0% у реальной модели): при разрушенной связи цены и спроса модельная реакция на цену ослабевает, и оптимизатор сильнее сдвигает цены вверх. Это означает, что величина модельного эффекта не является доказанным экономическим эффектом; меньший эффект реальной модели косвенно указывает, что она выучила более сильную ценовую реакцию. Практические выводы опираются на сценарный анализ с условными допущениями (10 / 25 / 50% реализации модельного эффекта);
- рекомендации на следующую неделю (`reports/рекомендации_следующая_неделя.csv`): 3 938 позиций активного ассортимента на неделю 02.11.2026;
- время обучения на 179 546 строках: LightGBM — 4,0 с, случайный лес — 195,0 с, XGBoost — 9,4 с, CatBoost — 70,3 с, пуассоновская GLM — 3,0 с. Полный цикл пересчёта (подготовка данных, обучение, оптимизация) — около 17 минут, из них чтение и агрегация выгрузки — около 11 минут (при повторных запусках без смены файла чтение кэшируется).

Примечание: признак «изменение цены, %» исключён из обучения — диагностика показала, что из-за протягивания цены в недели без продаж он косвенно кодировал целевую переменную (`reports/диагностика_изменения_цены.json`). Уровень цены и маржа также исключены из признаков: они кодируют товар и создают ложную «ценовую реакцию»; оставлены относительные ценовые признаки с монотонным ограничением −1 (по итогам плацебо-контроля).

Подробности — в `reports/`.
