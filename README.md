# Интеллектуальная система динамического ценообразования для интернет-магазина

Прототип, разработанный в рамках ВКР (бакалавриат, 09.03.03 «Прикладная информатика»).

## Состав
- `src/prepare_data.py` — очистка исходных продаж и агрегация к уровню «товар-неделя»;
- `src/train_model.py` — формирование признаков и обучение модели прогноза спроса (LightGBM, функция потерь Tweedie, монотонное ограничение −1 на ценовые признаки), сравнение с базовыми прогнозами, случайным лесом, XGBoost, CatBoost и пуассоновской GLM;
- `src/optimize_price.py` — подбор оптимальной цены перебором сетки ±15% с ограничениями (маржа ≥ 10%), ретроспективная оценка экономического эффекта;
- `src/recommend_next_week.py` — рекомендации цен на следующую неделю после конца данных (боевой режим работы системы);
- `src/validate_price_response.py` — диагностическая проверка согласованности прогнозируемой и наблюдаемой реакции продаж на изменение цены (вспомогательный сценарий анализа);
- `src/diagnose_price_change.py` — диагностика артефакта признака «изменение цены» (вспомогательный сценарий анализа);
- `src/sensitivity_analysis.py` — анализ чувствительности эффекта: ширина ценовой сетки, усиление модельной ценовой реакции, бутстрэп по товарам;
- `src/placebo_test.py` — плацебо-тест: обучение на ценах, перемешанных по времени внутри товара только в обучающем периоде (временная утечка исключена), и сравнение эффекта с реальной моделью;
- `src/app.py` — веб-интерфейс менеджера (Streamlit): рекомендации цен, карточка товара, журнал решений (SQLite);
- `tests/test_pipeline.py` — автоматические тесты конвейера (pytest, 8 тестов).

## Данные
История продаж интернет-магазина: товар, дата, категория, флаг акции, количество, суммы закупки и продажи. Исходный файл `Датасет.xlsx` размещается на уровень выше папки `Прототип` (в репозиторий не включается).

## Запуск
```bash
pip install -r requirements.txt
python src/prepare_data.py           # подготовка данных (один раз)
python src/train_model.py            # обучение модели
python src/optimize_price.py         # расчёт рекомендаций и эффекта
python src/sensitivity_analysis.py   # анализ чувствительности эффекта
python src/placebo_test.py           # плацебо-тест (перемешанные цены)
python src/recommend_next_week.py    # рекомендации на следующую неделю
python -m pytest tests -v            # автоматические тесты
streamlit run src/app.py             # веб-интерфейс
```

## Результаты (проверочный период — последние 8 недель)
- WMAPE прогноза спроса: 56,7% (наивный прогноз — 68,6%, скользящее среднее — 57,1%, случайный лес — 60,7%, XGBoost — 59,6%, CatBoost — 58,2%, пуассоновская GLM — 114,7%), MAE — 10,78 шт., смещение уровня спроса — −5,2%. Из ML-моделей лучший результат показал LightGBM, что и обосновывает его выбор;
- расчётный прирост прибыли в рамках используемой модели при рекомендованных ценах: +30,2% к фактическим ценам и +33,9% к стратегии «себестоимость + 30%» (не подтверждён реальным внедрением и требует проверки в A/B-тесте);
- устойчивость эффекта (`reports/анализ_чувствительности.json`): сетка ±5% → +13,1%, ±10% → +22,8%; усиление модельной ценовой реакции → +27,4%; бутстрэп-интервал модельной оценки по составу товаров — 95% [28,4%; 32,2%];
- диагностическая проверка ценовой чувствительности (`reports/проверка_ценовой_чувствительности.json`): совпадение знака реакции модели с фактическими изменениями продаж — 58,7%, ранговая корреляция Спирмена — +0,23; проверка носит диагностический характер и не подтверждает достоверность ценовой реакции;
- оценённая моделью эластичность спроса: медиана −1,31 (неэластичных позиций — 31,3%) — в пределах диапазона эмпирических оценок мета-анализа Tellis;
- плацебо-тест (`reports/плацебо_тест.json`): модели, обученные на ценах, перемешанных по времени внутри товара только в обучающем периоде (исходная согласованная во времени связь цены и продаж разрушена), показывают близкий WMAPE (57,3–57,9%) и даже больший модельный «эффект» оптимизации (53,4–55,4% против +30,2% у реальной модели): при разрушенной связи цены и спроса модельная реакция на цену ослабевает, и оптимизатор сильнее сдвигает цены вверх. Это означает, что величина модельного эффекта не является доказанным экономическим эффектом; меньший эффект реальной модели косвенно указывает, что она выучила более сильную ценовую реакцию. Практические выводы опираются на сценарный анализ с условными допущениями (10 / 25 / 50% реализации модельного эффекта);
- рекомендации на следующую неделю (`reports/рекомендации_следующая_неделя.csv`): 1 306 позиций активного ассортимента на неделю 02.11.2026;
- время обучения на 59 920 строках: LightGBM — 1,3 с, случайный лес — 14,9 с, XGBoost — 3,0 с, CatBoost — 56,4 с, пуассоновская GLM — 2,0 с.

Примечание: признак «изменение цены, %» исключён из обучения — диагностика показала, что из-за протягивания цены в недели без продаж он косвенно кодировал целевую переменную (`reports/диагностика_изменения_цены.json`). Уровень цены и маржа также исключены из признаков: они кодируют товар и создают ложную «ценовую реакцию»; оставлены относительные ценовые признаки с монотонным ограничением −1 (по итогам плацебо-контроля).

Подробности — в `reports/`.
