# Интеллектуальная система динамического ценообразования для интернет-магазина

Прототип, разработанный в рамках ВКР (бакалавриат, 09.03.03 «Прикладная информатика»).

## Состав
- `src/prepare_data.py` — очистка исходных продаж и агрегация к уровню «товар-неделя»;
- `src/train_model.py` — формирование признаков и обучение модели прогноза спроса (LightGBM), сравнение с базовыми прогнозами, случайным лесом и лог-лог регрессией;
- `src/optimize_price.py` — подбор оптимальной цены перебором сетки ±15% с ограничениями (маржа ≥ 10%), ретроспективная оценка экономического эффекта;
- `src/validate_price_response.py` — диагностическая проверка согласованности прогнозируемой и наблюдаемой реакции продаж на изменение цены (вспомогательный сценарий анализа);
- `src/diagnose_price_change.py` — диагностика артефакта признака «изменение цены» (вспомогательный сценарий анализа);
- `src/sensitivity_analysis.py` — анализ чувствительности эффекта: ширина ценовой сетки, усиление модельной ценовой реакции, бутстрэп по товарам;
- `src/placebo_test.py` — плацебо-тест: обучение на ценах, перемешанных по времени внутри товара только в обучающем периоде (временная утечка исключена), и сравнение эффекта с реальной моделью;
- `src/app.py` — веб-интерфейс менеджера (Streamlit): рекомендации цен, карточка товара, журнал решений (SQLite).

## Данные
История продаж интернет-магазина: товар, дата, категория, флаг акции, количество, суммы закупки и продажи. Исходный файл `Датасет.xlsx` размещается на уровень выше папки `Прототип` (в репозиторий не включается).

## Запуск
```bash
pip install -r requirements.txt
python src/prepare_data.py           # подготовка данных (один раз)
python src/train_model.py            # обучение модели
python src/optimize_price.py         # расчёт рекомендаций и эффекта
python src/sensitivity_analysis.py   # анализ чувствительности эффекта
python src/placebo_test.py           # плацебо-тест (перемешанные цены)
streamlit run src/app.py             # веб-интерфейс
```

## Результаты (проверочный период — последние 8 недель)
- WMAPE прогноза спроса: 53,6% (наивный прогноз — 68,6%, скользящее среднее — 57,1%, случайный лес — 53,3%, лог-лог регрессия — 89,8%), MAE — 10,19 шт.;
- расчётный прирост прибыли в рамках используемой модели при рекомендованных ценах: +39,3% к фактическим ценам и +28,1% к стратегии «себестоимость + 30%» (не подтверждён реальным внедрением и требует проверки в A/B-тесте);
- устойчивость эффекта (`reports/анализ_чувствительности.json`): сетка ±5% → +18,0%, ±10% → +30,5%; усиление модельной ценовой реакции → +53,2%; бутстрэп-интервал модельной оценки по составу товаров — 95% [36,2%; 42,6%];
- диагностическая проверка ценовой чувствительности (`reports/проверка_ценовой_чувствительности.json`): совпадение знака реакции модели с фактическими изменениями продаж — 55,7% (из 3 614 позиций с существенной реакцией модели), ранговая корреляция Спирмена — +0,17; проверка носит диагностический характер и не подтверждает достоверность ценовой реакции;
- плацебо-тест (`reports/плацебо_тест.json`): модели, обученные на ценах, перемешанных по времени внутри товара только в обучающем периоде (исходная согласованная во времени связь цены и продаж разрушена), показывают тот же WMAPE (53,7–53,9%) и сопоставимый или больший модельный «эффект» оптимизации (52,8–55,0%). Это означает, что величина +39,3% характеризует результат оптимизации в пределах заданной ценовой сетки при слабом модельном отклике спроса на цену, а не доказанный экономический эффект; практические выводы опираются на сценарный анализ с условными допущениями (10 / 25 / 50% реализации модельного эффекта);
- время обучения на 59 921 строке: LightGBM — около 2 с, случайный лес — около 17 с.

Примечание: признак «изменение цены, %» исключён из обучения — диагностика показала, что из-за протягивания цены в недели без продаж он косвенно кодировал целевую переменную (`reports/диагностика_изменения_цены.json`).

Подробности — в `reports/`.
